Observacoes operacionais

  • Esta tela existe apenas no sistema central SaaS identificado por APP_SYSTEM_ROLE=saas_central ou APP_CENTRAL_CONTROL_ENABLED=1.
  • O provisionamento SaaS depende de worker de jobs ativo para processar subscriber.environment.provision.
  • O cadastro agora diferencia o ambiente principal isolado do ambiente runtime usado pelo assinante.
  • No modelo compartilhado por coluna de assinante, varios assinantes podem apontar para o mesmo ambiente runtime sem misturar o ambiente principal.
  • O acompanhamento usa SSE quando disponivel e cai para polling quando necessario.
  • O pacote on-premise foi pensado para Ubuntu 24.04 e entrega install.sh como ponto de entrada.
  • Em outros ambientes, publicar esta tela exige rodar php backend/bin/console app:seed-runtime-metadata --no-interaction.
  • Em outros ambientes centrais, tambem configure APP_SYSTEM_ROLE=saas_central ou APP_CENTRAL_CONTROL_ENABLED=1 antes de expor a tela.
  • Sem a marcacao de sistema central e sem worker ativo, o provisionamento nao deve ser considerado operacional.
