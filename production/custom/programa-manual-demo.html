Programa manual

Esta pagina existe fora do motor CRUD. O catalogo runtime apenas registra `screenId`, permissao e entrypoint.

Uso

Serve para fluxos muito especificos, como telas dinamicas baseadas em condicoes cadastradas.

Governanca

Mesmo sendo manual, continua publicada pelo backend, com codigo de programa, versao e permissao.

Evolucao

Se o padrao se repetir, depois pode virar um novo tipo de pagina fechado no runtime.
