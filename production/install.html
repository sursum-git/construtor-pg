Observacoes operacionais

  • Esta pagina executa apenas etapas fechadas: migrations, seed, criacao do assinante/admin, publicacao do catalogo e integridade.
  • Antes de usar esta pagina, execute o instalador compilado do perfil correto para validar o assinante e criar a sessao local de ativacao.
  • Na primeira instalacao, defina uma senha do instalador no formulario; ela sera salva como hash em backend/.env.local.
  • Depois da instalacao, o backend grava APP_SYSTEM_INSTALLED=1.
  • Para reinstalar, execute nova ativacao pelo instalador compilado, informe a mesma senha do instalador, escolha a politica de backup e marque a confirmacao explicita de reinstalacao.
  • O backend deve ser reiniciado para aplicar mudancas salvas no .env.local ao processo web atual.
