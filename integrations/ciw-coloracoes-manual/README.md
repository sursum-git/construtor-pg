# Colorações — fonte API manual

Fonte `motor_progress_coloracoes_manual`, operação de lista `read`, já cadastrada no backend local. Programa Progress compilado no 12.2 e publicado no PASOE; consulta real validada com 41 registros em 15/10/2026. Este pacote contém somente metadados de consulta, sem nova tela publicada.

Memória central: [conversão Scriptcase](../../../conversao-sc/context/PROJECT_CONTEXT.md).

Programa, compilação e roteiro de seleção no construtor: [exemplo completo](../../../conversao-sc/examples/coloracoes-manual/README.md).

O marcador `__RUNTIME_SECRET__` não é uma credencial real. O token fica exclusivamente no backend. Salvar a entidade após mudar fonte/operação para atualizar seu snapshot. Não selecionar esta fonte na entidade de empresas.
