Ajuda do Cadastro de Clientes

Consulta

Use os filtros para localizar clientes por nome, e-mail, status ou periodo de cadastro.

Manutencao

Use Novo para criar registros e as acoes da grade para visualizar, editar ou excluir clientes.

Leiautes

O menu Leiaute permite salvar configuracoes do grid com nome e definir um leiaute como padrao.
