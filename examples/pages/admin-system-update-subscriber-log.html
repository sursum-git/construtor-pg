Observacoes operacionais

  • Esta pagina local usa demo em memoria para a consulta central por assinante.
  • No sistema real, ela so deve ficar disponivel no sistema central identificado por APP_SYSTEM_ROLE=saas_central ou APP_CENTRAL_CONTROL_ENABLED=1.
  • No sistema real, o historico depende do log de execucao preenchido pelo updater central.
  • Em outros ambientes reais, publique a tela com php backend/bin/console app:seed-runtime-metadata --no-interaction.
  • Para ter historico util no ambiente real, o sistema central precisa manter o worker do updater ativo e registrar as execucoes por assinante.
  • No sistema do assinante, esta consulta nao deve aparecer.
